# NL2SQL 真实数据输出执行总览（Codex）

## 1. 目标
把项目最终成功输出从“SQL 文本为主”升级为“真实数据为主”，即成功态统一为 `type='result'` 且携带 `data.rows`。

## 2. 批次拆分
| 批次 | 计划文件 | 核心目标 | 依赖 |
|---|---|---|---|
| D1 | `01-D1-审计摘要基建计划.md` | 审计结果摘要化，消除业务行落库 | 无 |
| D2 | `02-D2-agentic主路径执行闭环计划.md` | agentic 主路径执行 SQL 并回数 | D1 |
| D3 | `03-D3-澄清恢复执行闭环计划.md` | 澄清恢复路径执行 SQL 并回数 | D1, D2 |
| D4 | `04-D4-SSE与前端兼容计划.md` | SSE/前端契约切换到 data-first | D2, D3 |
| D5 | `05-D5-测试回归与验收计划.md` | 新增专项测试并形成验收证据 | D1-D4 |

## 3. 执行顺序
1. D1（审计与数据最小化）
2. D2（主路径回数）
3. D3（澄清回数）
4. D4（协议与前端收口）
5. D5（测试与交付）

## 4. 里程碑门禁
| 门禁 | 条件 |
|---|---|
| G1 | D1 单测通过，`query_history.result` 不含业务 rows |
| G2 | D2 后 agentic 主路径返回 `type='result'` + `data` |
| G3 | D3 后澄清恢复路径返回 `type='result'` + `data` |
| G4 | D4 后前端默认展示数据结果，老会话兼容 |
| G5 | D5 后专项测试、smoke、真实依赖回归形成记录 |

## 5. 风险总控
| 风险 | 控制措施 |
|---|---|
| 执行时延上升 | 保留 `FF_AGENTIC_ENGINE`、`DRY_RUN` 回滚 |
| 数据安全回退 | 执行统一走 `sqlExecutor.validateSQL/executeQuery` |
| 老会话渲染异常 | 前端保留 `sql_result` 兼容分支 |
| 真实环境不可测 | D5 强制给出 skip 原因与补测计划 |

## 6. 交付件
1. D1-D5 每批次交接摘要（执行完成后生成）
2. `docs/NL2SQL-真实数据输出完工摘要.md`
3. 测试报告（smoke + phase-data + 真实依赖）
